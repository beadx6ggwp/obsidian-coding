# Naming Rules

## File Names

使用清楚、可搜尋的 English technical terms，必要時加中文補充。

建議格式：

- Concept note: `Concept - Topic.md`
- Implementation note: `Impl - Topic.md`
- Debug note: `Debug - Symptom.md`
- Reading note: `Reading - Source Title.md`
- Command note: `Command - Tool or Task.md`
- Project decision: `Decision - YYYY-MM-DD - Topic.md`

## Links

- 優先使用 Obsidian wiki links：`[[note name]]`
- 專案內相對連結由 Obsidian 自動維護。
- 同一概念第一次出現時，盡量連到 canonical note。

## Tags

Tags 用來補充橫向脈絡，不取代資料夾分類。

例：

- `#graphics`
- `#cpp`
- `#debugging`
- `#devops`
- `#fullstack`
- `#pixel-renderer`
